# Техническое задание

На языке программирования С/[[С++]], для любого микроконтроллера, реализовать нижеописанный [[протокол RPC]].

- Интерфейс - [[hw/UART/UART|UART]].
- Использование [[RTOS/RTOS|RTOS]] обязательно.
- К ответу приложить исходный код на [[git/GitHub|GitHub]].
- Приложить описание реализации.
- Сделать предложения по улучшению протокола.
- Рассмотреть недостатки протокола.
