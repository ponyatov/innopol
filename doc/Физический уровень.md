# Физический уровень
## [[протокол RPC]]

Физический уровень отвечает за непосредственную отправку пакетов или последовательности байт в некоторую среду передачи данных. Эта среда должна быть асинхронной, либо поддерживать асинхронную обертку.  Для каждой среды реализация физического уровня является уникальной.
