# Канальный уровень
## [[протокол RPC]]

Канальный уровень отвечает за формирование пакетов при передаче. и разделение входящего потока байт на пакеты при приеме. Для проверки целостности данных используется контрольная сумма.

Формат пакета для канального уровня:

|   |   |   |   |   |   |   |
|---|---|---|---|---|---|---|
|№ байта|0|1|2|3|4|5…n|
|Значение|0xFA|l_l|l_h|crc8|0xFB|x|
|Расшифровка|стартовый байт|младший байт длины пакета|старший байт длинны пакета|контрольная сумма заголовка|стартовый байт данных|сообщение транспортного уровня|

|   |   |   |
|---|---|---|
|№ байта|n+1|n+2|
|Значение|crc8|0xFE|
|Расшифровка|контрольная сумма всего пакета|стоповый байт|

```C
/// @brief Channel layer packet
struct Channel {
    uint8_t start = 0xFA;  //< start byte
    uint16_t length;       //< package length (`l_l`/`l_h`, little endial)
    uint8_t crc8;          //< ^header check sum
    uint8_t data = 0xFB;   //< data frame marker
    uint8_t message[];     ///< @ref Transport layer packet
} __attribute__((packed));
```
